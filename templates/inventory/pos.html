Avtomatik (tavsiya)

WebUSB (chekisiz)
  • Faqat Chrome / Edge / Opera (Safari'da yo'q), HTTPS shart.
  • Tugma bosilganda printerni tanlab "Connect" bosing — keyingi safar eslab qoladi.
Native driver

Lokal printer driverni default qiling; kassir Cmd+P bilan bosadi.

Modellar: Xprinter XP-58/80mm, Star TSP100, Epson TM-T20, POS-58 — barchasi ESC/POS.
